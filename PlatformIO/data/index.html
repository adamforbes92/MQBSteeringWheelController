General Setup

Must match the bus you're wired to. VW powertrain CAN is 500; the comfort/infotainment bus a radio listens on is 100. At the wrong speed nothing gets through in either direction and the controller goes bus-off. Changing this reboots the device.

Assign a button the Charisma flag in Button Builder to drive this. MQB button mode emulates the dash button and lets the car's own coordinator cycle the mode; MQB coordinator mode commands each participant's target program directly. PQ works differently — one mode value for the whole car, carried in a multiplexed slot of the comfort gateway's Gate_Komf_1, and it has no button signal at all, so coordinator is the only route.

All of these IDs are normally transmitted by the gateway, so on a car that already has Drive Select this device becomes a second transmitter of an existing ID. PQ is the riskiest: 0x390 also carries brake lights, indicators, reverse and door contacts, and everything we don't set goes out as zero. Sniff for the ID before enabling.

Participants to command

Byte carrying scroll-wheel movement and, for ordinary buttons, the wheel's own press-stage counter (1 pressed, 4 once held ~0.8 s) — byte 3 on both wheels seen so far. A roller sends the same code whichever way it turns, so learn it once, duplicate the row, and set the Trigger column to Scroll up on one and Scroll down on the other. Short/Long press split a held button the same way.

CAN Monitor

        

          Off by default and never persisted — it always starts off after
          a reboot. With no ID filter this records each distinct ID once,
          which is how to find out what a bus actually carries; a busy 500 kbit/s
          bus would otherwise fill the 300-frame buffer in well under a second.
          Set a filter ID to follow one message instead. Export writes SavvyCAN's
          CSV column order, so the file opens there directly.
        

        

          
          
          
          
          
          
        

        

      


      

        
SavvyCAN Analyzer

        

          Streams every received frame to a real analyzer, with no buffer limit
          — use this instead of the monitor above when you need a full
          capture. Over WiFi: SavvyCAN → Add New Device Connection →
          Network Connection (GVRET), this device's IP, port 23. Over serial:
          GVRET Compatible Device on the COM port. The two are mutually
          exclusive, and serial mode reopens the USB port at 1 Mbaud,
          so the debug console is unusable while it runs.
